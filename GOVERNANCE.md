# Governance / プロジェクト運営

CrystalTwinAI is a community-oriented **research-software** project. Initial stewardship and merge decisions are held by the repository maintainers (the owner `Takzin1`); collaborator and reviewer roles may be added openly as contributions grow. This document does not promise a formal foundation, industrial certification, or response-time SLA.

## Decisions

- Discuss feature ideas and scientific claims in Issues and PRs.
- Keep scientific limitations visible in documentation and exported reports.
- Use CI on Node 20/22; don't waive unit/provenance/safety tests for convenience.
- Preserve exact source evidence and review rights before incorporating measured datasets.
- Seek reviewer input on numerical methods, accessible design, and software supply-chain changes.

## Releases and compatibility

No published SemVer-stable API or validated process-control release is guaranteed. Contributors should mark breaking schema changes and propose migration notes. A future tagged version may use a release checklist and independent archive DOI; none is asserted today.

## Maintainers and contributors

Questions and proposals: GitHub Issues. Responsible security disclosure: [SECURITY.md](SECURITY.md). Community conduct: [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

This governance policy can be amended by maintainers following public discussion.
