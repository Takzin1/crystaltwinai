# Support / サポート

CrystalTwinAI is maintained as an open research/education project on a best-effort basis.

- Bugs, reproducibility failures and access issues: [GitHub Issues](https://github.com/Takzin1/crystaltwinai/issues).
- Code changes and documentation fixes: [CONTRIBUTING.md](CONTRIBUTING.md).
- Scientific assumptions and measurement provenance: include source DOI, native units, replicate conditions and minimal test cases in an Issue.
- Security: [SECURITY.md](SECURITY.md), **not** a public bug report.
- Data rights and attribution: [THIRD_PARTY_DATA.md](THIRD_PARTY_DATA.md).

No warranty of experimental accuracy, equipment-control suitability, clinical safety, support duration or production uptime is provided.
