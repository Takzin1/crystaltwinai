# Design Principles / 設計原則

## 中核思想

> AIとデジタルツインで無駄な作業や理解コストを減らし、人間が本質的な判断・学習・安全責任に集中できるようにする。

## 原則

1. **AIは道具、人間が判断主体(Human-in-the-loop)**
   推薦は自動実行されず、常に人間の操作を介する。スマート学習工場におけるHITL/On-the-loop型デジタルツインの知見に基づく。

2. **説明可能性ファースト(Explainable by construction)**
   すべての推薦・リスク判定は「なぜそう判定したか」の理由文を必ず持つ。プロセス産業向け人間中心XAIのガイドライン(EXPLAIN Guidebook)に沿い、ブラックボックス推薦を採用しない。初期版がルールベースなのは、透明性と教育効果を優先した意図的な選択である。

3. **決定論的で再現可能なシミュレーション**
   同じ入力は常に同じ出力を返す。学習者が仮説→操作→観察のループを回せることを最優先する。

4. **モジュール分離と差し替え可能性**
   config(値・文言・閾値)/ lib(計算ロジック)/ components(表示)を分離。推薦モジュールはML・MPC・外部APIに同一インターフェースで差し替え可能。

5. **教育的に正直なモデル**
   物理的厳密性よりも「因果が読める」ことを優先した簡略化モデルを採用し、その旨を明示する。実モデル(人口収支モデル、MPC、ML予測制御)への発展経路はロードマップとして文書化する。

6. **安全境界の内蔵**
   実設備制御・安全判断・医療判断への使用禁止を、README・UI・ドキュメントの3層で明示する。
